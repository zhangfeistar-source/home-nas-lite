# 家庭 NAS Lite 产品规格

## 目标
在一台 Windows 10/11 电脑上选择真实目录作为家庭共享根目录，同一 Wi-Fi 内的手机、平板和电脑通过浏览器完成登录、浏览、上传、下载、整理、回收与预览。

## MVP 用户旅程
1. 首次启动选择共享目录，设置家庭访问码和管理员密码，可选放行仅限 `LocalSubnet` 的 TCP 实际端口。
2. 应用在 `8787-8799` 中选择可用端口，主窗口和托盘显示本机与局域网地址。
3. 家人输入访问码获得 HttpOnly Session，在文件、最近上传、回收站和设置之间操作。
4. 普通删除进入共享根目录下隐藏的 `.recycle-bin`，30 天后清理；永久操作要求管理员密码。

## 范围
- 包含：文件夹浏览、搜索、上传、下载、ZIP、新建、重命名、移动、删除、恢复、预览、最近上传、状态。
- 预览：图片、浏览器支持的视频、FLV、PDF、文本、DOCX、XLSX/XLS/CSV。
- 不包含：公网、云同步、账号、自动备份、转码、SMB、原生移动 App、复杂权限。

## 体验与兼容
- 中文、接近 Windows 文件资源管理器、少动画、触控目标不小于 40px。
- 桌面采用侧栏和文件表格；窄屏改为可横向滚动列表及底部/折叠导航。
- FLV 由本地 `flv.js` 通过 Media Source Extensions 播放，支持常见 H.264 + AAC/MP3 编码组合。
- 其他视频能力以浏览器解码支持为准；MKV、AVI、HEVC 等不保证播放并提供下载提示。

## 验收
- `npm run dev` 可启动。
- `npm test` 覆盖认证、路径安全、文件生命周期、回收站冲突、Range 和中文路径。
- `npm run verify` 检查静态资产、配置、安全关键项和安装脚本。
- `npm run dist` 生成 `dist/家庭NAS-Setup-1.0.0.exe`，目标机无需 Node.js。
