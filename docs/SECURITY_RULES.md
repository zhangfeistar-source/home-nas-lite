# 安全规则

1. 客户端路径必须先 `decodeURIComponent` 安全处理，再标准化为 POSIX 相对路径；拒绝盘符、反斜杠、UNC、绝对路径、NUL、空段、`.` 与 `..`。
2. 任何文件系统操作均通过统一安全解析器；现存路径使用 `realpath`，并比较大小写不敏感的根路径边界。
3. 对每级目录使用 `lstat` 拒绝符号链接、Junction 和其他 reparse-point 可疑入口；`.recycle-bin` 不允许由普通文件 API 访问。
4. 上传临时文件位于应用数据目录，目标路径验证完成后再移动；失败必须清理临时文件。
5. 下载、Range、ZIP 仅打开已校验的普通文件；响应头对文件名进行安全编码。
6. 访问码和管理员密码使用随机盐 `scrypt`，配置中不得保存明文。
7. Session ID 使用密码学随机数；Cookie 为 HttpOnly、SameSite=Strict；登录失败采用短时速率限制。
8. 管理员密码只用于当次永久删除、清空和设置修改，不提升持久 Session 权限。
9. Electron 禁止 Node 集成，启用上下文隔离和沙箱；导航与新窗口仅允许本机应用 URL，外链交给系统浏览器。
10. 防火墙命令固定规则名、协议和端口，远端地址固定 `LocalSubnet`，不得拼接未经校验的 IPC 输入。
11. 安装与卸载脚本不得删除共享根目录；应用数据仅在用户明确选择时删除。
12. 日志不得记录密码、Session Cookie 或文件正文。
